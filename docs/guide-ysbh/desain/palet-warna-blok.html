Palet Warna untuk Elemen Blok

Disusun dari warna yang sudah benar-benar terpakai di seluruh halaman dan komponen CMS — bukan palet baru. Tujuannya supaya penambahan blok baru ke depan konsisten tanpa perlu menebak lagi warna mana untuk bagian apa.

1

Token Inti

Sembilan warna dasar yang menjadi sumber seluruh elemen blok di bawah. Dua pasang (Foresty/Forest, Goldy/Goldy Soft, Coral/Coral Dark) sengaja punya varian gelap-terang untuk kondisi default vs hover/aktif.

7

Indikator Status — Khusus Admin

Bukan bagian dari warna konten blok. Dua warna ini (Amber, Green) cuma dipakai di sisi admin file manager — titik status "sedang dipakai/belum dipakai" dan label terkait. Sengaja dipisah dari token inti supaya tidak tercampur dipakai di halaman publik.

Sedang dipakai
Belum dipakai
Status Berkas (File Manager)
Dipakai — Amber #B8860B
Latar peringatan — Amber Soft #FBF0D9
Aman — Green #1F7A4D
Latar aman — Green Soft #E3F3EA
Kenapa dipisah: Coral sudah dipakai untuk aksi destruktif (tombol Hapus), jadi Amber/Green dipilih khusus supaya status "boleh/tidak boleh dihapus" tidak ambigu dengan warna tombol aksinya sendiri. Kalau nanti ada blok publik yang butuh makna "berhasil/peringatan" (misal status formulir), dua warna ini bisa dipakai juga — tapi sejauh ini belum ada kasusnya di halaman publik.
